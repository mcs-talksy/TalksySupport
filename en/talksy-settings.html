Talksy Settings

Learn by Speaking

Appearance

App Theme Talksy

Set the application color pallet:

  • Talksy: Use Talksy's own colour palette.
  • System: Follow your iPhone's Light/Dark mode.
Background Color Yellow

Set the background colour. Only visible when App Theme is set to Talksy.

Navigation Background * Dark Gloss

Set the background of the lessons map:

  • Dark Gloss: Use a dark gloss background.
  • Checkerboard: Use a red/white checkerboard background.
Navigation Selection * Pulsating

Set how the current lesson is highlighted on the lessons map:

  • Pulsating: Use a pulsating token to indicate selection.
  • Glow: Use a background glow to indicate selection. This is the energy-efficient option and uses less battery.
Show Welcome Screen On

Show the welcome/onboarding screens when Talksy launches.

Lesson Configuration

Speaking Accuracy 85%

The minimum match percentage your spoken answer needs to reach for an exercise to be marked correct.

Speaking Accuracy (Vocab) 50%

Same idea as Speaking Accuracy, but for vocabulary exercises.

Speaking Accuracy (Junior) * 50%

A separate, more forgiving accuracy threshold used specifically for younger learners.

Max Exercise Failures 5

How many unsuccessful attempts are allowed on an exercise before the dreaded sad cat.

Playback Rate * 0.45

Adjusts the speed of spoken narration. Slower is easier, turn it down for beginners.

Preferred Voice * Prefer Gender

Set the text-to-speech voice(s) Talksy uses:

  • Use Default: Use the default voice for selected language.
  • Prefer Gender: Use two high quality voices, one male and one female.
  • Prefer Quality: Use one high quality voice, either male or female.
Auto Play Exercises On

Automatically plays the audio for an exercise as soon as it opens.

Auto Playback Recordings On

Automatically plays back your own recording after you finish speaking.

Show Native Text * On

Shows the text of exercises in your native language.

Show Learning Text * On

Shows the text of exercises in the language you're learning.

Show Attempts Count * On

Show how many attempts you made at the current exercise.

Allow Exercise Skipping * Off

Lets you skip past an exercise without completing it. Enable if an exercise proves impossible to pass.

Please report any such exercises.

Allow Vocabulary Skipping * On

Lets you skip past a vocabulary item without completing it.

Auto Play

Announce Course * Off

Plays a short spoken introduction for the course before playback begins.

Announce Lesson * On

Plays a short spoken introduction for each lesson before it begins.

Translate Exercise On

Plays a translation of the current exercise.

Repeat Slowly On

Repeat the current exercise slowly.

Repeat Normally Off

Repeat the current exercise at normal speed.

Beep Between Exercises * Off

Plays a short beep between exercises.

Pause Breaks * 2s

Length of the pause inserted between exercises during hands-free playback.

Repeat Count * 1

How many times the auto play sequence is repeated.

Auto Play — Interactive

Enable Interactive Mode * Off

Turns on interactive hands-free playback, where Talksy waits for your spoken response before continuing.

Failure Policy * Repeat Slowly

What Talksy does after a single unsuccessful attempt.

  • Repeat Exercise: Repeat the entire exercise sequence.
  • Repeat Normally: Repeat the current exercise at normal-speed.
  • Repeat Slowly: Repeat the current exercise a slowed-down, word-by-word.
  • Skip: Skip the current exercise.
  • Stop: Stop the autoplay.
Max Failure Policy * Skip

What Talksy does after you've reached the maximum number of unsuccessful attempts.

  • Repeat Exercise: Repeat the entire exercise sequence.
  • Repeat Normally: Repeat current exercise at normal-speed.
  • Repeat Slowly: Repeat current exercise word-by-word.
  • Skip: Skip the current exercise.
  • Stop: Stop the autoplay.
Timeout * 15s

How long Talksy waits for a spoken response before treating the attempt as missed.

External Directories

External Directories * None

Add folders on your device containing custom course content for Talksy to load.

Debug

Proof Mode * Off

A review aid used while proofreading lesson content — for debugging purposes only.
