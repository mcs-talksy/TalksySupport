Erscheinungsbild

App-Design Talksy

Legt die Farbpalette der Anwendung fest:

  • Talksy: Verwendet Talksys eigene Farbpalette.
  • System: Folgt dem Hell-/Dunkelmodus Ihres iPhones.
Hintergrundfarbe Gelb

Legt die Hintergrundfarbe fest. Nur sichtbar, wenn das App-Design auf Talksy eingestellt ist.

Navigationshintergrund * Dunkel glänzend

Legt den Hintergrund der Lektionskarte fest:

  • Dunkel glänzend: Verwendet einen dunklen, glänzenden Hintergrund.
  • Schachbrett: Verwendet einen rot-weißen Schachbrett-Hintergrund.
Navigationsauswahl * Pulsierend

Legt fest, wie die aktuelle Lektion auf der Lektionskarte hervorgehoben wird:

  • Pulsierend: Verwendet ein pulsierendes Symbol zur Kennzeichnung der Auswahl.
  • Leuchten: Verwendet ein leuchtendes Hintergrundglühen zur Kennzeichnung der Auswahl. Diese Option ist energieeffizient und verbraucht weniger Akku.
Begrüßungsbildschirm anzeigen Ein

Zeigt die Begrüßungs-/Einführungsbildschirme beim Start von Talksy an.

Lektionskonfiguration

Sprechgenauigkeit 85 %

Der minimale Übereinstimmungsprozentsatz, den Ihre gesprochene Antwort erreichen muss, damit eine Übung als richtig markiert wird.

Sprechgenauigkeit (Vokabeln) 50 %

Gleiches Prinzip wie bei der Sprechgenauigkeit, jedoch für Vokabelübungen.

Sprechgenauigkeit (Junior) * 50 %

Ein separater, nachsichtigerer Genauigkeitsschwellenwert speziell für jüngere Lernende.

Maximale Übungsfehlversuche 5

Wie viele erfolglose Versuche bei einer Übung erlaubt sind, bevor die gefürchtete traurige Katze erscheint.

Wiedergabegeschwindigkeit * 0,45

Passt die Geschwindigkeit der gesprochenen Erzählung an. Langsamer ist leichter — für Anfänger reduzieren.

Bevorzugte Stimme * Geschlecht bevorzugen

Legt die von Talksy verwendete(n) Sprachausgabe-Stimme(n) fest:

  • Standard verwenden: Verwendet die Standardstimme für die ausgewählte Sprache.
  • Geschlecht bevorzugen: Verwendet zwei hochwertige Stimmen, eine männliche und eine weibliche.
  • Qualität bevorzugen: Verwendet eine hochwertige Stimme, entweder männlich oder weiblich.
Übungen automatisch abspielen Ein

Spielt die Audiodatei einer Übung automatisch ab, sobald diese geöffnet wird.

Aufnahmen automatisch abspielen Ein

Spielt Ihre eigene Aufnahme automatisch ab, nachdem Sie zu sprechen aufgehört haben.

Muttersprachlichen Text anzeigen * Ein

Zeigt den Text der Übungen in Ihrer Muttersprache an.

Lernsprachlichen Text anzeigen * Ein

Zeigt den Text der Übungen in der Sprache an, die Sie lernen.

Anzahl der Versuche anzeigen * Ein

Zeigt an, wie viele Versuche Sie bei der aktuellen Übung unternommen haben.

Überspringen von Übungen erlauben * Aus

Ermöglicht es, eine Übung zu überspringen, ohne sie abzuschließen. Aktivieren Sie dies, wenn eine Übung sich als unlösbar erweist.

Bitte melden Sie solche Übungen.

Überspringen von Vokabeln erlauben * Ein

Ermöglicht es, ein Vokabelelement zu überspringen, ohne es abzuschließen.

Automatische Wiedergabe

Kurs ansagen * Aus

Spielt vor Beginn der Wiedergabe eine kurze gesprochene Einführung zum Kurs ab.

Lektion ansagen * Ein

Spielt vor Beginn jeder Lektion eine kurze gesprochene Einführung ab.

Übung übersetzen Ein

Spielt eine Übersetzung der aktuellen Übung ab.

Langsam wiederholen Ein

Wiederholt die aktuelle Übung langsam.

Normal wiederholen Aus

Wiederholt die aktuelle Übung in normaler Geschwindigkeit.

Signalton zwischen Übungen * Aus

Spielt einen kurzen Signalton zwischen den Übungen ab.

Pausenlänge * 2 s

Länge der Pause, die während der Freisprech-Wiedergabe zwischen den Übungen eingefügt wird.

Wiederholungsanzahl * 1

Wie oft die automatische Wiedergabesequenz wiederholt wird.

Automatische Wiedergabe — Interaktiv

Interaktiven Modus aktivieren * Aus

Aktiviert die interaktive Freisprech-Wiedergabe, bei der Talksy auf Ihre gesprochene Antwort wartet, bevor es fortfährt.

Verfahren bei Fehlversuch * Langsam wiederholen

Was Talksy nach einem einzelnen erfolglosen Versuch tut.

  • Übung wiederholen: Wiederholt die gesamte Übungssequenz.
  • Normal wiederholen: Wiederholt die aktuelle Übung in normaler Geschwindigkeit.
  • Langsam wiederholen: Wiederholt die aktuelle Übung verlangsamt, Wort für Wort.
  • Überspringen: Überspringt die aktuelle Übung.
  • Stoppen: Stoppt die automatische Wiedergabe.
Verfahren bei maximalen Fehlversuchen * Überspringen

Was Talksy tut, nachdem Sie die maximale Anzahl erfolgloser Versuche erreicht haben.

  • Übung wiederholen: Wiederholt die gesamte Übungssequenz.
  • Normal wiederholen: Wiederholt die aktuelle Übung in normaler Geschwindigkeit.
  • Langsam wiederholen: Wiederholt die aktuelle Übung Wort für Wort.
  • Überspringen: Überspringt die aktuelle Übung.
  • Stoppen: Stoppt die automatische Wiedergabe.
Zeitlimit * 15 s

Wie lange Talksy auf eine gesprochene Antwort wartet, bevor der Versuch als verpasst gewertet wird.

Externe Verzeichnisse

Externe Verzeichnisse * Keine

Fügen Sie Ordner auf Ihrem Gerät hinzu, die eigene Kursinhalte enthalten, die Talksy laden soll.

Debug

Korrekturmodus * Aus

Eine Korrekturhilfe für das Gegenlesen von Lektionsinhalten — nur für Debugging-Zwecke.
